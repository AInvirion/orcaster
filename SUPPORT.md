# Support

Orcaster is maintained by AInvirion LLC. Community support is best effort.

## Where to go

| You want to | Go to |
|---|---|
| Ask a question or share an idea | A new [issue](https://github.com/AInvirion/orcaster/issues) |
| Report a bug | A new issue with the **Bug report** template |
| Request a feature | A new issue with the **Feature request** template |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue |
| Contribute code or documentation | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Anything else | contact@ainvirion.com |

## Before you ask

- Read the [README](README.md) and the guide of the component you use.
- Search open and closed issues for the same problem.
- Include the Orcaster version (`orcaster version` prints it), your operating system and the exact error message.
