View worker contract

Commands and requirements: the worker creates an ephemeral venv from payload.requirements (list of pip specs) and then executes payload.commands sequentially via /bin/sh -c within that venv. commands must be a non-empty list of strings; requirements may be empty. Any other payload shape is rejected with exit code 2.

Artifacts: when the optional payload.artifacts block is present, the worker collects the files the task wrote to $ORCASTER_ARTIFACTS_DIR — filtered by the include/exclude POSIX globs — and uploads them. Without the block nothing is collected.

Isolation: the reserved payload.task_env and payload.egress_allowlist keys are tri-state. Absent means legacy mode (no isolation). Present but empty ([]) means strict mode (clean environment / all egress denied). Present with values forwards only those env vars / allows only those domains.
